GTM Engineering - API Simulation

This is a static JSON API served via GitHub Pages for educational purposes. Use fetch(), Postman, or curl to hit the endpoints below.

Available Endpoints

GETapi/accounts.json

Returns aggregated account summaries: owner, tags, total emails sent/opened/replied, open rate, and reply rate.

GETapi/account-analytics.json

Returns daily analytics per account: date, emails sent, emails opened, and replies for each sending account.

GETapi/campaign-analytics.json

Returns daily campaign analytics: campaign name, date, emails sent, emails opened, and positive replies.

Example Usage

// Fetch account summaries
fetch('https://<username>.github.io/gtmeng_api_simulation/api/accounts.json')
  .then(res => res.json())
  .then(data => console.log(data));

// Fetch daily analytics
fetch('https://<username>.github.io/gtmeng_api_simulation/api/account-analytics.json')
  .then(res => res.json())
  .then(data => console.log(data));

// Fetch campaign analytics
fetch('https://<username>.github.io/gtmeng_api_simulation/api/campaign-analytics.json')
  .then(res => res.json())
  .then(data => console.log(data));
